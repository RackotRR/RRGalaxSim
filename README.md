Система моделирования динамики галактики методами NBody и Particle-Mesh.

Параллельная версия на CUDA C++. 
Можно собирать солвер отдельно от GUI и взаимодействовать с ним через параметры в формате json (см. sample). На вход солвер требует один аргумент - папку с `params.json`.

GUI построен на python + streamlit.
